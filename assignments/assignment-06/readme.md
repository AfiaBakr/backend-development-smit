# Question 1 — Basic Array Methods

Create an array named `fruits` containing at least 5 fruit names.

- Use `length` to display the number of elements.
- Use `toString()` to convert the array into a string.
- Use `at()` to access at least two elements using indexes.
- Use `join()` to display the elements separated by a symbol or text.
- Display each result using `console.log()`.

# Question 2 — Adding and Removing Array Elements

Create an array named `students` containing at least 5 student names.

- Use `push()` to add a student to the end.
- Use `pop()` to remove the last student and display the removed value.
- Use `unshift()` to add a student to the beginning.
- Use `shift()` to remove the first student and display the removed value.
- Display the array after each operation.
- Use `length` at the end to display the final number of students.

# Question 3 — concat(), slice(), splice() and delete

Create two arrays of your choice and practice combining, copying, modifying, and deleting array elements.

- Use `concat()` to combine the two arrays into a new array.
- Use `slice()` to create a new array containing a selected portion of the original array.
- Use `splice()` to remove at least one element.
- Use `splice()` again to add at least one element at a specific position.
- Use the `delete` operator to delete one array element using its index.
- After `delete`, display the array and its length. Observe what happens to the deleted position.
- Display the important results using `console.log()`.

> **Important:** Observe the difference between `delete` and `splice()`. After `delete`, the array position becomes empty/undefined while the array length remains unchanged.
