# Question 1 — Responsive Layout Using CSS Grid

Design the following webpage layout using HTML and CSS Grid. The design must be responsive for both desktop/web and mobile devices using appropriate CSS breakpoints and media queries.

### Requirements

* Use CSS Grid for the main page layout.
* Create appropriate breakpoints for responsiveness.
* Use media queries to change the layout at different screen sizes.
* Make the design responsive for desktop, tablet, and mobile screens.
* On smaller screens, rearrange or stack the sections appropriately.
* Try to match the overall structure, spacing, typography, colors, and alignment of the reference design as closely as possible.
* You may use your own text, icons, and images, but the overall layout should remain similar to the reference.

# Question 3 — JavaScript Variables & Data Types

* Use `typeof` to display/check the type of your variables.
