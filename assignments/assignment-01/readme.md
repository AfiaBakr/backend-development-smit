# HTML Basics — Assignment 01

**Topics Covered:** Introduction to the Web, HTML Document Structure, Headings, Paragraphs, Lists, Links, Images, Tables, Forms, Semantic HTML  
**Difficulty:** Beginner  
**Total Questions:** 4

## Instructions

- Complete all 4 questions.
- Write valid HTML5 code.
- Use proper indentation and meaningful content.
- Do not use CSS or JavaScript.
- Save each task as a separate `.html` file.
- Make sure each webpage opens correctly in a browser.

---

## Question 1 — Create Your First HTML Web Page

Create a basic HTML5 webpage titled **"My Introduction"**.

Your webpage must contain:

- A proper HTML5 document structure.
- A `<title>` inside the `<head>`.
- An `<h1>` containing your name.
- An `<h2>` containing **"About Me"**.
- A paragraph introducing yourself.
- Another paragraph explaining why you are interested in learning web development.
- An unordered list containing at least 3 hobbies or interests.
- An ordered list containing at least 3 goals you want to achieve as a web developer.

### Task

Write the complete HTML code for this webpage.

---

## Question 2 — Links and Images

Create a webpage called **"My Favorite Websites"**.

The page should contain:

- A heading: **"My Favorite Websites"**
- A paragraph explaining which websites you frequently use.
- At least 3 links to different websites.
- Each link should open in a new browser tab.
- Add an image below the links.
- The image must contain appropriate `alt` text.
- Make the image clickable so that clicking the image opens a website.

### Task

Write the HTML code required to create this webpage.

**Hint:** Think about how `<a>` and `<img>` can be used together.

---

## Question 3 — Create a Student Marks Table

Create a webpage containing a table titled **"Student Marks"**.

Use the following data:

| Roll No | Student Name | HTML | CSS | Total |
|---|---|---:|---:|---:|
| 101 | Ali | 80 | 75 | 155 |
| 102 | Sara | 90 | 85 | 175 |
| 103 | Ahmed | 70 | 80 | 150 |
| 104 | Ayesha | 95 | 90 | 185 |

Your HTML table must:

- Have a heading above the table.
- Use `<table>`, `<tr>`, `<th>`, and `<td>` correctly.
- Have a proper header row.
- Contain all four students and their marks.
- Include a `<caption>` describing the table.

### Task

Write the complete HTML code for the table.

---

## Question 4 — Create a Student Registration Form

Create a webpage called **"Student Registration Form"**.

The form should collect the following information:

- **Full Name** — text input
- **Email** — email input
- **Password** — password input
- **Date of Birth** — date input
- **Gender** — radio buttons
- **Favorite Programming Languages** — checkboxes with at least 3 options
- **City** — dropdown/select menu with at least 4 cities
- **About Yourself** — textarea
- **Submit button**
- **Reset button**

Your form should also use appropriate `<label>` elements for the form fields.

### Task

Write the HTML code for this registration form.

**Bonus:** Make the Name, Email, and Password fields required.
