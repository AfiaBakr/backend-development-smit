## Question 5 — Build a Complete Personal Profile Page

**New HTML + CSS Task:** Unlike Questions 1–4, this webpage was NOT part of Assignment 01. Create both the HTML and CSS from scratch.

Create `profile.html` and `profile.css` for a **Personal Profile / Student Portfolio** page.

### HTML Requirements

* Use `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, and `<footer>`.
* **Header:** your name and a short title such as “Aspiring Web Developer”.
* **Navigation:** at least 3 links.
* **About section:** your image, a heading, and a short introduction paragraph.
* **Skills section:** at least 5 skills.
* **Article:** “My Journey into Web Development” with at least one paragraph.
* **Aside:** additional information such as hobbies, favorite technology, or career goal.
* **Footer:** your name, copyright text, and at least one contact link.

### CSS Requirements

* **Selectors:** use element, class, and ID selectors.
* **Colors:** apply colors to the page background, header, navigation, sections, text, and buttons/links.
* **Typography:** apply font family, font size, font weight, text alignment, and appropriate line height.
* **Box Model:** apply margin, padding, border, width, and height where appropriate.
* **Display:** use at least one appropriate display property.
* **Positioning:** use relative or absolute positioning somewhere on the page.
* **Units:** use at least three different units, such as `px`, `%`, `rem`, `vh`, or `vw`.
* **Flexbox:** use Flexbox as the primary layout method for at least one major section, using properties such as `display: flex`, `justify-content`, `align-items`, `gap`, and `flex-direction`.
