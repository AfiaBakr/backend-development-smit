## Question 1 — Online Store Sales Report

You are helping an online store analyze its daily sales. The store has recorded the following order amounts:

```javascript
[1200, 450, 3000, 750, 1500, 250, 4200, 900].
```

* The manager wants to know the first order amount greater than 2000.
* The manager wants a separate list containing all orders greater than 1000.
* The manager wants to know the combined total of all order amounts.
* Display the original array and all required results clearly in the `console.log`
* Use an `arrow function` for at least one of the operations.

A teacher has a list of student marks and wants to prepare a quick performance report:

```javascript
[45, 78, 92, 61, 88, 54, 73, 95].
```

* Create another list containing only students whose marks are 70 or above.
* Find the first mark greater than 90.

* Display each result and keep the original marks unchanged.

Imagine that an API returns the following employee data: 


## Question 4 - Store Inventory Using JavaScript Map

A small store wants to keep its inventory in a JavaScript Map. Start with these products and quantities:

```
[apples: 500, bananas: 300, oranges: 200]
```

* Create the inventory as a Map.
* Add a new product to the inventory.
* The quantity of one existing product changes. Update the stored quantity.
* Retrieve and display the quantity of a specific product.
* Check whether a particular product exists in the inventory and display the result.
* Remove one product from the inventory.
* Display the current number of product entries.
* Display all product names and all quantities.
* Use a Map iteration technique to print each product and quantity in a readable format.
